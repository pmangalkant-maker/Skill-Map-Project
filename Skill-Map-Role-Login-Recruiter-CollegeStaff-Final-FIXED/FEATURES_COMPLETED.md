# Skill Map — Completed Scope

## Career intelligence
- Resume upload/parsing (PDF/DOCX)
- Automatic upload -> resume parsing -> skill extraction -> skill-gap pipeline
- Resume analysis summary (candidate/contact/education/experience/certifications/projects/skills)
- Skill extraction with Gemini plus deterministic fallback when AI is unavailable
- Skill extraction, verification and skill-gap analysis
- Industry-aligned skill assessment questionnaire
- Role matching and learning roadmap
- AI Career Assistant with provider/fallback logic

## Student
- Dashboard, profile, skills, jobs/internships
- Application tracking
- Digital portfolio (summary, projects, certifications, achievements, links)

## Industry / Recruiter
- Opportunity publishing
- Required skills, location, experience, compensation and deadline
- Candidate matching/readiness and shortlist workflow

## Academia
- Faculty internships, industrial training, FDP
- Mentorship, workshops, guest lectures
- Innovation challenges, live projects, research and consultancy

## Institution
- Placement-readiness and skill analytics
- Opportunity/application/internship metrics

## 3D experience
- Real WebGL/Three.js animated skill network on the landing page
- Mouse-responsive depth/parallax
- 3D dashboard atmosphere
- Animated skill nodes, links, core geometry and star field

## Run
Backend: `cd backend && npm install && npm run dev`
Frontend: `cd frontend && npm install && npm run dev`
